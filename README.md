# Brownian-theory

# Brownian Motion Simulation
## 足し算だけで熱運動と拡散を再現する

> *"The universe computes with addition alone."*

---

## 概要

このリポジトリは、**加算のみ**によるブラウン運動シミュレーションです。

三角関数も微分方程式も確率密度関数も使いません。
**24方向の整数テーブルと足し算だけ**で、熱運動・拡散・エントロピー増大を再現します。

## 核心：3つの足し算の連鎖

### 1. 熱運動
24方向の整数テーブルからランダムに選んで速度に加算する。
これが「水分子の衝突」に相当します。

### 2. 拡散
密度を8近傍に10%ずつ分配する。
∇²ρ = D・∂ρ/∂t（拡散方程式）の代わりです。

### 3. 方向シフト
ステップ数で方向インデックスをシフトする。
渦のような局所的な秩序が、足し算の副産物として自然に発生します。

---

## 繋がった2点（異物）

河に竿を出したとき、竿先の2点が流れに揺られながら漂うイメージです。

- **質量 8**（軽い）→ 流れに乗りやすい
- **摩擦 0.98**（小さい）→ 慣性で漂い続ける
- **双方向結合** → 流体が異物を動かし、異物が流体を動かす

軌跡:          ランダムウォーク（花粉粒子と同じパターン）
